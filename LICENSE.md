# Lizenzhinweise

Supersynergy stellt Ruf und die zugehörigen Downloads in diesem privaten Repository bereit. Für die App und die Produktdokumentation ist keine Open-Source-Lizenz angegeben.

Für enthaltene Drittkomponenten gelten deren eigene Lizenzen. Das Disk-Image enthält die Hinweise der beim Build verwendeten Rust-Standardbibliothek unter `Hinweise/Rust-Standardbibliothek.html`. Die Android SDK Platform-Tools werden separat von Google bezogen.

Die Herkunft des Produktbilds ist im [Bildnachweis](docs/assets/README.md) dokumentiert.
