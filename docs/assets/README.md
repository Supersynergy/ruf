# Produktbild

`social-preview.png` zeigt das native Wählfenster von Ruf mit der Kurzwahl, wie sie in Version 2.3.1 aussieht. Für die Aufnahme wurde die App-Oberfläche mit drei erfundenen Kontakten und Beispielnummern geladen. Die Aufnahme wurde für die README mit dem Ruf-Schriftzug auf dunkelgrünem Grund gesetzt. Die Titelgrafik ist 1280 × 640 Pixel groß. Ein Klick darauf öffnet die unbeschnittene Aufnahme `waehltastatur.png`. Das Ruf-Symbol stammt aus dem App-Paket.
